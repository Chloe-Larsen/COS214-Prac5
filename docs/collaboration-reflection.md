# GitHub Repository Link and Collaboration Reflection

Repository: https://github.com/Chloe-Larsen/COS214-Prac5

The team worked using a feature-branch workflow, with each major piece of work (design docs, UML project file, core implementation, documentation) developed on its own branch and merged into main via pull request. This gave the team a reviewable history and kept main stable throughout development. Task delegation was communicated via WhatsApp, splitting work into four tasks (design/implementation, sequence diagrams, and engineering-quality documentation) with a shared deadline ahead of the Tuesday 29 September demo.
